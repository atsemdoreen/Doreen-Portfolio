# Doreen Atsem – Developer Portfolio

Static portfolio built with HTML, CSS and JavaScript.

## Before publishing, replace
- `YOUR-EMAIL@example.com` (index.html and script.js)
- `YOUR-USERNAME` / `YOUR-REPO` GitHub links
- LinkedIn URL, official IBM credential URL, Netlify URL
- The About text, project cards and screenshots (`images/projects/`)
- Search index.html for "YOUR-" and "EDIT:" to find everything

## Publish
    git init
    git add .
    git commit -m "Create initial portfolio"
    git branch -M main
    git remote add origin YOUR_GITHUB_REPOSITORY_URL
    git push -u origin main

Then import the repo in Netlify (publish directory: repository root).
